# Data

## ShanghaiT2DM: real, open, anonymised

- **What:** 100 adults with Type 2 diabetes from two Shanghai hospitals, in 109 sensor periods. Each period has CGM every 15 minutes, fingersticks, meals (food names and weights), insulin and tablet doses, all time-stamped. A summary sheet adds age, sex, BMI, HbA1c, kidney function, complications, drugs and history of lows.
- **Source:** [Chinese diabetes datasets for data-driven machine learning](https://www.nature.com/articles/s41597-023-01940-7), Scientific Data, 2023. Official files: [figshare](https://doi.org/10.6084/m9.figshare.c.6310860).
- **Licence:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). The official archive credits **Qinpei Zhao, Jinhao Zhu, Congrong Wang and Weixiong Rao**. Source: [figshare article 21600933](https://doi.org/10.6084/m9.figshare.21600933).
- **This copy:** taken from a [public GitHub copy](https://github.com/Kartikey-Bartwal/Shanghai-Diabetes-Dataset-to-detect-if-the-person-has-type-1-or-type-2-diabetes) of the release. It includes the T2DM subset (109 period files and one summary workbook), reorganised into the layout below. The supplied files were retained so the published results remain reproducible against `results/manifest.json`.
- **Official-source verification, 24 October 2026:** all 110 files were compared with the official archive, figshare file `42966622`. **98 are byte-identical; nine more have identical parsed cell contents; one summary heading differs only in capitalisation; two period files differ in observations/timestamps.** In particular, period `2003_0_20210615` is shorter and `2029_0_20210526` has missing timestamps and a shorter tail in the mirror. The supplied results describe this mirror-derived subset, not an exact reproduction on the official archive. See [the comparison report](../docs/data_provenance.md) and [per-file hashes](../docs/data_source_comparison.json).
- **Changes and derived work:** repository packaging reorganises the supplied source files. Parsing, unit handling, sensor correction and modelling occur in code; their outputs are separate in `results/`. The source data retain CC BY 4.0 and are not relicensed as Apache-2.0. Attribution does not imply endorsement by the dataset authors.
- **Layout:**
  - `shanghai_t2dm/Shanghai_T2DM_Summary.xlsx`
  - `shanghai_t2dm/periods/<patient>_<period>_<start date>.xlsx` (some files are `.xls`)

## Synthetic Indian cohort: generated

Generated by our own scripts (`scripts/make_cohort.py`): example record shapes modelled on India's ABDM FHIR R4 guide, with CYP2C9 and G6PD status where tested, and smartwatch streams shaped like Android Health Connect records. The files have not been validated against those profiles, and no compliance is claimed. Each persona's physiology is copied from one real patient's calibration-fitted core. Synthetic data drives demos and illustrative scenarios only; it never grades a model.
